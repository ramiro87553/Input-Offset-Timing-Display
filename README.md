# Input Offset & Timing Display

A Geode mod for Geometry Dash 2.2 that provides real-time visual feedback on input timing accuracy and frame offsets.

## Features

- Real-time Offset Display measuring millisecond differences between player inputs and engine physics ticks.
- Color-coded precision feedback:
  - Green: Excellent timing (< 4ms offset)
  - Yellow: Moderate offset (4ms - 8ms)
  - Red: Late / Early timing (> 8ms offset)
- Minimalist HUD lightweight Cocos2d-x overlay.
- Geode SDK v4 Compatible built for GD 2.2+.

## Installation

1. Open Geometry Dash and go to the Geode menu.
2. Search for Input Offset & Timing Display.
3. Click Install and restart your game.
